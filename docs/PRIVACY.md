# KnoWell 隐私政策

**更新日期：** 2026-08-13  
**适用：** iOS App「KnoWell / 致知」（`com.knowellcards.app`）

本页供 App Store 审核与用户查阅。应用将闪卡保存在本机，不运营用户账号后端。

## 我们收集什么

默认情况下，KnoWell **不收集** 可用于识别你身份的数据，也没有自己的云端用户库。

保存在你 iPhone 上的内容包括：卡片、复习进度、设置、你自行填写的 AI API Key。导出的 JSON 备份由你保管。

## 相机与相册

相机用于扫描文字以生成卡片。相册选用系统选择器。OCR 在设备本地通过 Apple Vision 完成，图片不会为了识别而上传。

## AI 制卡（自备 Key）

若你填写了 API Key 并生成卡片，原文与生词会发送到你选择的 AI 服务商（如 Kimi / DeepSeek 或自定义接口）。KnoWell 不运营存储这些内容的服务器。

## 官方免费额度

未填写自己的 API Key 时，制卡请求经过致知的转发服务。服务端只保存匿名设备编号与「今日已用次数」，用于显示剩余次数并限制每日免费调用。不保存卡片内容、词库或复习记录。

## 分享扩展

从其他 App 分享进来的文本/图片仅用于在本机制卡，处理方式与主 App 相同。

## 登录与同步

当前版本不提供微信或 Apple 登录，也不使用 iCloud 同步。换机请使用应用内备份导出/导入。
