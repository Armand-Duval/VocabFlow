## 2. 三 Tab 信息架构

```
Tab 1 复习（默认）  今日总览 + 开始复习 + 快捷制卡
Tab 2 词库          搜索 / Deck / 卡片列表
Tab 3 制卡          AI 导入制卡

设置 → 各页右上角 ⚙️，Sheet 呈现（不占底栏）
```

## 3. 页面布局

### 3.1 复习（首页）

```
左：致知 KnoWell     右：Deck 筛选 · ⚙️
┌─────────────────────────────┐
│ 待复习 │ 新词配额 │ 连续学习 │  白卡片三栏
└─────────────────────────────┘
[        开始复习        ]       唯一强 CTA（#239678）
  📷   🖼   📋                 紧凑线性圆图标
最近词库（浅灰小字）
词库名 ······· 数量
```

### 3.2 词库

- 通栏搜索 + 右上筛选 / 词库管理 / ⚙️  
- Deck chip 横向滑动  
- 瘦列表行：词 + 一句语境 + 轻量状态  
- 无底栏导入导出（进词库管理）

### 3.3 制卡

- 无居中大标题  
- 紧凑线性图标：相册 / 拍照 / 粘贴  
- 通栏输入：`粘贴英文段落、书籍文本`  
- 词列表 + Deck 选择  
- 底栏：`AI 一键生成`（无内容时置灰）

## 5. UX 原则

1. 信息前置：今日任务在 C 位  
2. 能图标就不堆文字  
3. 底栏只留每日必点三入口  
4. 路径最短：首页可直达制卡  
5. 克制弹窗与 streak 绑架（连续天数仅小栏展示）
